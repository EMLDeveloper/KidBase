# KidBase — MoSCoW Prioritization

## 🔴 Must Have (MVP)

### Authentication & Access

- As an admin, I can register an account so that I can access the system.
- As a user, I can log in securely so that my data is protected.
- As an admin, I can assign roles to users so that each person only sees what they need.

### Child Enrollment

- As an admin, I can register a new child so that they are enrolled in the system.
- As an admin, I can view all enrolled children so that I can manage the roster.
- As an admin, I can update a child's information so that records stay current.
- As an admin, I can deactivate a child's profile so that withdrawn students are no longer active.

### Attendance

- As a staff member, I can check in a child so that their arrival is recorded.
- As a staff member, I can check out a child so that their departure is confirmed.
- As an admin, I can view today's attendance so that I know who is present.

### Documents

- As an admin, I can upload enrollment documents so that physical paperwork is eliminated.
- As an admin, I can retrieve any document quickly so that I don't have to search physical files.

### Staff Management

- As an admin, I can add a staff member so that they can access the system.
- As an admin, I can view all staff members so that I can manage my team.

### Notifications

- As a parent, I can receive a notification when my child is checked in so that I know they arrived safely.
- As a parent, I can receive a notification when my child is checked out so that I know they were picked up.

---

## 🟠 Should Have (Version 1.1)

### Billing & Payments

- As an admin, I can generate a monthly invoice so that parents are billed correctly.
- As an admin, I can track outstanding balances so that I can follow up on late payments.
- As an admin, I can view full payment history so that I have a centralized payment record.
- As a parent, I can view my invoices so that I know what I owe.
- As a parent, I can view my payment history so that I have a record of all transactions.

### Infant Monitoring

- As a staff member, I can log infant observations digitally every 15 minutes so that I no longer record them on paper.
- As a staff member, I can view previous infant logs so that I can track patterns.

### Incident Reporting

- As a staff member, I can file an incident report so that the event is officially documented.
- As a parent, I can receive an incident notification so that I am informed immediately.

### Historical Records

- As an admin, I can search past attendance records so that I can review historical data quickly.
- As an admin, I can search past payment records so that I can resolve billing disputes.

---

## 🟡 Could Have (Version 1.2)

### Daily Operations

- As a staff member, I can view the daily menu so that meals are organized and consistent.
- As a staff member, I can view the activity schedule so that the day runs smoothly.
- As an admin, I can create and update weekly menus so that meal planning is centralized.

### Staff Scheduling

- As an admin, I can create staff schedules so that coverage is always planned.
- As a staff member, I can view my schedule so that I know when I work.

### Analytics & Reporting

- As an admin, I can view an enrollment report so that I understand growth trends.
- As an admin, I can view a revenue report so that I can make informed business decisions.
- As an admin, I can export reports so that I can share them with my accountant.

---

## ⚪ Won't Have (Future)

- Mobile application
- Online payment processing
- AI-powered features
- Multi-location support
- Third-party integrations
