# KidBase — User Stories

## Admin / Owner

### Enrollment

- As an admin, I want to register a new child so that they are officially enrolled in the system.
- As an admin, I want to view all enrolled children so that I can manage current capacity.
- As an admin, I want to update a child's information so that records stay accurate.
- As an admin, I want to upload and store enrollment documents so that physical paperwork is eliminated.

### Attendance

- As an admin, I want to view daily attendance reports so that I can monitor who is present.
- As an admin, I want to access historical attendance records so that I can review past data quickly.

### Billing & Payments

- As an admin, I want to generate monthly invoices so that parents are billed correctly.
- As an admin, I want to track payment history so that I have a centralized record of all transactions.
- As an admin, I want to flag outstanding balances so that I can follow up on late payments.

### Staff

- As an admin, I want to add and manage staff profiles so that they can access the system.
- As an admin, I want to view staff schedules so that I can manage coverage and ratios.

### Operations

- As an admin, I want to manage the weekly menu so that meals are organized and accessible digitally.
- As an admin, I want to schedule activities so that daily operations are structured and consistent.

---

## Staff / Teacher Assistants

### Attendance

- As a staff member, I want to check in a child so that their arrival is recorded in the system.
- As a staff member, I want to check out a child so that their pickup is confirmed and logged.

### Child Information

- As a staff member, I want to view a child's profile so that I have access to medical notes and emergency contacts.
- As a staff member, I want to log infant monitoring updates every 15 minutes so that manual paper records are eliminated.

### Operations

- As a staff member, I want to view the daily menu so that I know what meals to prepare.
- As a staff member, I want to view the activity schedule so that I can plan the day accordingly.

---

## Parents / Guardians

### Notifications

- As a parent, I want to receive a notification when my child is checked in so that I know they arrived safely.
- As a parent, I want to receive a notification when my child is checked out so that I know who picked them up.

### Child Information

- As a parent, I want to view my child's profile so that I can verify their information is accurate.
- As a parent, I want to view infant monitoring logs so that I can see updates about my baby throughout the day.

### Billing

- As a parent, I want to view my invoices so that I know what I owe and when payment is due.
- As a parent, I want to view my payment history so that I have a record of all transactions.

### Documents

- As a parent, I want to upload required documents digitally so that I don't have to deliver physical paperwork.

---

## Security & Access

- As an administrator, I want users to have appropriate access based on their role so that sensitive information is protected.
- As a user, I want to securely log into KidBase with JWT authentication so that my account and data are protected.
